# ubuntu_dot_files_and_config_dir
 ubuntu dot_files (for home folder) and dot_config_dir (for home folder)

==> idea is put all dot_files and dot_config_files in a single_or_central dir (under home_dir) and then symlink all these dot file to their desired location_path 

==> so, if you made changes in the dot file which present in this central dir then automatically same_changes happen of its symlink_file
==> same way, if you made changes in the dir which present in this central dir then automatically same_changes happen of its symlink_dir

 - for (dot_config) --> put all files and dirs under it --> to ~/.config/
 - for (dot_files_in_home_dir) --> put all files and dirs under it --> to ~/
